# Estado del prototipo

## Alcance

Este repositorio contiene el prototipo oficial presentado a The Fragrance Bar, desarrollado para Aterna Studio. Es una presentación funcional con contenido de muestra, no una tienda operativa. La condición de prototipo oficial no implica aprobación de todos sus contenidos ni autorización para explotación comercial.

Los precios son de demostración, el checkout no cobra y los formularios no envían mensajes. Algunos datos de tiendas, horarios, reseñas y textos están pendientes de confirmación. Los enlaces externos de contacto y WhatsApp sí pueden abrir servicios reales.

## Visibilidad recomendada

Se mantiene pública esta versión de presentación para conservar GitHub Pages y permitir su revisión como proyecto. No se recomienda utilizar este repositorio público como archivo de trabajo interno del negocio. Debe contener únicamente código y recursos destinados a la demostración, documentación de mantenimiento y datos de muestra.

El código que se entrega al navegador siempre puede inspeccionarse, incluso si su repositorio de origen es privado. Ocultar el repositorio no hace confidenciales los recursos publicados. `noindex` tampoco controla el acceso.

Si el proyecto incorpora material interno, la recomendación es desarrollar esa parte en un repositorio privado y conservar aquí únicamente la presentación pública. No se ha creado una copia privada ni se ha migrado el desarrollo en esta revisión.

GitHub Pages con GitHub Free exige un repositorio público. En planes compatibles se puede publicar desde uno privado, pero no se cambia la visibilidad sin comprobar primero el plan y el despliegue. [Disponibilidad de GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).
